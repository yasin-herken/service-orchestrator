# 2. Project Context

Service Orchestrator is a local macOS developer orchestration platform.

It manages multiple repositories, shared libraries, builds, migrations, processes, and development workflows.

The application consists of:

- Rust Application Core
- Shared Local Daemon
- Task Engine and Scheduler
- Workflow Engine
- Git Manager
- Build Manager
- Library Manager
- Migration Manager
- Process Manager
- Service Runtime
- Health Manager
- Observability
- Unix Domain Socket IPC
- Ratatui TUI
- MCP Server
- Tauri 2 + React + TypeScript GUI

The application is intended for local development.

It must remain usable without an LLM.

The primary target is approximately 40 repositories, with support for 100+ configured services.

# 31. Defect Classification

Classify findings:

**Critical**
- Data loss
- Unauthorized database mutation
- Killing unrelated processes
- Credential exposure
- Duplicate authoritative daemon

**High**
- Broken workflows
- Incorrect task state
- Process leaks
- Deadlocks
- Incorrect dependency ordering

**Medium**
- UI inconsistencies
- Missing diagnostics
- Recoverable operation failures
- Performance regressions

**Low**
- Minor UX defects
- Documentation inconsistencies
- Non-critical visual issues

Fix Critical and High defects before declaring release readiness.
