## Role

Act as a Principal Rust Engineer, Senior Tauri 2 Engineer, React/TypeScript Architect, and macOS Desktop UX Engineer.

You are implementing **Task 020 — Git, Build & Library Management GUI** of the Service Orchestrator project.

Your goal is to expose the existing Git Manager, Build Manager, and Library Manager capabilities through a professional macOS desktop interface.

# 7. Bulk Git Synchronization

This is a critical feature.

The user must be able to select multiple repositories and synchronize them to a target branch.

Example:

```text
Selected Repositories: 40

Target Branch:
master

Operations:
[x] Fetch
[x] Checkout
[x] Fast-forward pull

[Preview] [Execute]
```

Use the existing workflow planning and execution APIs.

Do not implement synchronization as an uncoordinated loop of frontend requests.

The daemon must own the bulk operation.

# 9. Git Safety

Never silently discard local changes.

For repositories with unsafe checkout/pull conditions:

- Display the issue.
- Preserve local modifications.
- Skip or block the unsafe operation.
- Show the repository-specific result.

Do not automatically stash, reset, clean, or force checkout.

Destructive Git operations are outside this task unless already implemented with a trusted authorization mechanism.
