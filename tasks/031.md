- Health Manager
- Observability

# 4. Packaging Architecture

Preserve the shared daemon architecture.

```text
Service Orchestrator.app
        |
        +---- Tauri GUI
        |
        +---- Bundled Rust Orchestrator Executable
                    |
                    +---- Local Daemon
                    +---- TUI Mode
                    +---- MCP Mode
```

The desktop application must not introduce a second orchestration engine.

The existing Rust executable must remain the authoritative implementation of orchestration operations.

# 14. Daemon Startup

When the user launches the macOS application:

1. Initialize the GUI.
2. Locate the bundled orchestrator executable.
3. Check whether a compatible daemon is running.
4. Connect if available.
5. Otherwise start the daemon safely.
6. Wait for readiness.
7. Establish IPC communication.
8. Load the active workspace.
9. Display the dashboard.

Reuse the existing daemon startup and single-instance mechanisms.

Do not create a competing daemon implementation.
