# 28. Duplicate Action Prevention

Prevent accidental duplicate requests caused by repeated clicks.

Example:

```text

Start auth-service
Start auth-service
```

must not create three service processes.

Use frontend pending-state protection and existing backend operation coordination.

Frontend protection alone is insufficient.

# 29. Daemon Disconnection

When the daemon disconnects:

- Display a clear disconnected state.
- Disable mutating actions.
- Attempt safe reconnection.
- Refresh service state after reconnecting.
- Do not automatically replay uncertain mutating operations.

---

# 30. Workspace Switching

- Cancel obsolete read requests where practical.

- Refresh dashboard counters.

Do not mix services from different workspaces.
