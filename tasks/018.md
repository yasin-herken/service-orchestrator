# 6. Desktop Rust Adapter

The Tauri Rust backend must act as a thin adapter.

Its responsibilities:

- Connect to the existing local daemon
- Invoke existing IPC operations
- Map IPC results to frontend-safe data
- Subscribe to daemon events
- Forward events to React
- Handle connection errors
- Manage desktop window lifecycle

It must not:

- Execute Git commands directly
- Execute Maven/npm directly
- Start services independently
- Create a second Task Engine
- Create a second Process Manager
- Parse service configuration independently
