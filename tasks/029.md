# 2. Project Context

Service Orchestrator is a local macOS developer orchestration application.

Its purpose is to manage multiple microservice repositories and local development environments without requiring developers to open every project in an IDE.

The application supports:

- Git repository management
- Maven and npm builds
- Shared library preparation
- Liquibase migrations
- Local service lifecycle management
- Health checks
- Realtime logs
- Task monitoring
- Development workflows
- Multiple workspaces
- Ratatui TUI
- MCP integration
- Tauri 2 + React + TypeScript desktop GUI

The system uses a shared local Rust daemon.

The application must work without an LLM or internet connection for operations that do not inherently require network access.
